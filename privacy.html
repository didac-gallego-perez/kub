Privacy policy

Last updated: November 7, 2026

Kub is a graphical interface for Windows Package Manager (winget). This policy explains what data the app handles.

Data the app collects

None. Kub has no user accounts, no telemetry or analytics, no advertising, and does not send any information to the developer's servers.

Data stored on your device

  • Preferences (theme, language, install mode, skipped updates, recent searches) in %LOCALAPPDATA%\Kub\settings.json.
  • Caches of app icons, download statistics and "Official" checks in %LOCALAPPDATA%\Kub.
  • A diagnostic log with technical errors in %LOCALAPPDATA%\Kub\log.txt.

You can delete these files at any time. They are removed when you uninstall the app.

Internet connections

To work, Kub connects to:

  1. The sources configured in winget (such as the winget community repository and Microsoft Store), through Windows Package Manager itself, to search, install and update apps. Those connections are governed by each source's terms.
  2. Each vendor's servers, to download the installer of the app you choose.
  3. To check whether an app is official, the public winget manifest repository (raw.githubusercontent.com/microsoft/winget-pkgs) and, for Microsoft Store apps, the public Store catalog service.
  4. To show logos, screenshots and popularity, the winget icon CDN, Microsoft Store images, the public UniGetUI icon database on GitHub, the GitHub and Chocolatey public APIs, and, when needed, the app's official repository or website listed in its manifest.

These requests only carry the standard technical information of any web connection (such as your IP address and a user agent that identifies Kub). No personal data and no list of your apps is sent.

Política de privacidad

Última actualización: 7 de noviembre de 2026

Kub es una interfaz gráfica para el Administrador de paquetes de Windows (winget). Esta política explica qué datos trata la aplicación.

Datos que recoge la aplicación

Ninguno. Kub no tiene cuentas de usuario, no incluye telemetría ni analíticas, no muestra publicidad y no envía información a servidores del desarrollador.

Datos que se quedan en tu equipo

  • Preferencias (tema, idioma, modo de instalación, actualizaciones omitidas, búsquedas recientes) en %LOCALAPPDATA%\Kub\settings.json.
  • Cachés de iconos, estadísticas de descargas y comprobaciones de «Oficial» en %LOCALAPPDATA%\Kub.
  • Un registro de diagnóstico con errores técnicos en %LOCALAPPDATA%\Kub\log.txt.

Puedes borrar estos archivos cuando quieras. Se eliminan al desinstalar la aplicación.

Conexiones a Internet

Para funcionar, Kub se conecta a:

  1. Los orígenes configurados en winget (como el repositorio de la comunidad de winget y Microsoft Store), a través del propio Administrador de paquetes de Windows, para buscar, instalar y actualizar aplicaciones. Esas conexiones se rigen por las condiciones de cada origen.
  2. Los servidores de cada fabricante, para descargar el instalador de la aplicación que eliges.
  3. Para comprobar si una aplicación es oficial, al repositorio público de manifiestos de winget (raw.githubusercontent.com/microsoft/winget-pkgs) y, para las aplicaciones de Microsoft Store, al servicio público del catálogo de la Store.
  4. Para mostrar logotipos, capturas y popularidad, a la CDN de iconos de winget, a las imágenes de Microsoft Store, a la base pública de iconos de UniGetUI en GitHub, a las API públicas de GitHub y Chocolatey y, si hace falta, al repositorio o a la web oficial de la aplicación indicados en su manifiesto.

En estas peticiones solo viaja la información técnica estándar de cualquier conexión web (como la dirección IP y un agente de usuario que identifica a Kub). No se envía ningún dato personal ni la lista de tus aplicaciones.
